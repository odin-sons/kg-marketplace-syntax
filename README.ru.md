# KG Marketplace Syntax Highlighting

[English](README.md) | По-русски

Расширение для Visual Studio Code, добавляющее подсветку синтаксиса для конфигурационных файлов `.cfg` мода [**KG Marketplace**](https://kg.sayless.eu/marketplace/#Start%20Page) игры Valheim.

## Описание

Это расширение облегчает чтение и редактирование файлов конфигурации, используемых в KG Marketplace, подсвечивая различные элементы синтаксиса, такие как типы квестов, профили неигровых персонажей, комментарии, переменные и специальные теги.

## Основные возможности

- **Комментарии**: Строки, начинающиеся с `#`, подсвечиваются как комментарии.
- **Профили**: Заголовки секций, заключенные в квадратные скобки (например, `[Trader]`), выделяются для лучшей навигации по файлу.
- **Типы квестов**: Распознаются и подсвечиваются основные типы квестов, такие как `Talk`, `Kill`, `Collect`, `Craft` и другие.
- **Опции диалогов**: Ключевые слова в диалогах, такие как `Text:`, `Transition:`, `Command:`, `Icon:`, `Condition:` и другие, выделяются для наглядности.
- **Теги форматирования**:
    - **Цвет**: `<color=#RRGGBB>...</color>`
    - **Жирный текст**: `<b>...</b>`
    - **Курсив**: `<i>...</i>`
    - **Размер шрифта**: `<size=NUMBER>...</size>`
    - **Изображения**: `<image=path/to/image>`
- **Переменные**: Переменные, заключенные в знаки процента (например, `%player_name%`), подсвечиваются.
- **Числа и координаты**: Числовые значения и координаты формата `X, Y, Z` выделяются.
- **Флаги территорий**: Специальные флаги, такие как `Circle`, `PvpOnly`, `NoBuild` и другие, распознаются и подсвечиваются.

## Установка

1.  Откройте Visual Studio Code.
2.  Перейдите в раздел **Extensions** (Ctrl+Shift+X).
3.  Найдите "KG Marketplace Syntax" в Marketplace.
4.  Нажмите **Install**.

Либо вы можете установить его из файла, упаковав его с помощью `vsce package` и установив через `Install from VSIX...`.

## Использование

После установки расширение автоматически активируется для всех файлов с расширением `.cfg`. Просто откройте любой такой файл, и вы увидите подсветку синтаксиса.
